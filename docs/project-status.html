Deploy Checklist (nová instance / nový klient)

Nová instance (jednorázově)

  • 1 npx wrangler pages project create fio-banka --production-branch main
  • 2 npx wrangler kv namespace create FIO_KV → ID zapsat do wrangler.toml
  • 3 Vygenerovat SESSION_SECRET + ADMIN_SECRET + (volitelně) ADMIN_TOTP_SECRET a nastavit přes wrangler pages secret put
  • 4 npx wrangler pages deploy . --project-name fio-banka

Nový klient (přes admin panel)

  • 1 Přihlásit do /admin → kliknout + Novy klient
  • 2 Vyplnit ID, název, heslo. Účty: jen názvy (klient si tokeny přidá sám) NEBO názvy + tokeny (admin-managed)
  • 3 Volitelně: IP allowlist (pro restriktivní přístup)
  • 4 Klepnout Test API pro ověření tokenů (volitelně)
  • 5 Zkopírovat Link (/?c=ID) a poslat klientovi
  • 6 Klient: otevře link, zadá heslo, nastaví TOTP přes QR, hotovo

2026-05-29
v3.8 — Oponentura security hardening (7 features)
Reakce na externí oponenturu (3 kritické, 5 závažných nálezů):
#2 Session revocation: sessionVersion per principal v KV, hard cutover starých tokenů. Změna hesla / MFA invaliduje všechny session.
#5 Re-auth pro správu tokenů: 5min reauth-token s prefixem "r." vyžadovaný pro POST/PUT/DELETE /api/client/accounts a change-password.
Audit eventy pro mutations: client_account_added/updated/removed, admin_client_created/updated/deleted s polem "changes".
Privacy v Test API: admin už nevidí číslo účtu / IBAN / zůstatek — jen "Token funguje" + počet transakcí.
Bulk Test API: tlačítko v adminu testuje všechny klienty × účty + cron worker denně 04:00 UTC do auditu.
Audit filtrace: filtry typ/klient/IP/limit, counter, CSV export (UTF-8 BOM).
2026-05-28
v3.7 — MFA self-service + admin force + UX polish
Klient může v profilu vypnout MFA (jen když si změnil heslo) — toggle button mění barvu podle stavu (červené Vypnout / modré Zapnout / šedé 🔒 zamčené).
Admin má v seznamu klientů tlačítko MFA on (žluté když off) / Reset (šedé když on). Force MFA resetuje passwordChangedByClient — klient nemůže znovu vypnout dokud si znovu nezmění heslo.
UX: kompaktní admin tabulka (ikony pro Edit/Smazat, fits desktop bez scrollu), favicon (F gradient).
2026-05-28
v3.6 — Bezpečnostní balík (3 features)
1. Klient si změní heslo: tlačítko v profile screen. Min 4 znaky (PIN-style, kompenzuje povinné TOTP). Admin zůstává min 6 znaků.
2. Rate limiting: 10 failů / 15 min per IP zablokuje další pokusy (HTTP 429). Sliding window v KV, scopes client_login a admin_login separátně.
3. Hashed hesla: PBKDF2-SHA256 / 100k iterations / 16B salt. Backward-compat: plain hesla se auto-migrují na hash při prvním loginu (admin i klient). Verifikace timing-safe.
2026-05-28
v3.5.1 — Test konzole + striktní stavy + barevné tlačítko
Test API tlačítko v admin seznamu klientů má teď neutrální (šedou) výchozí barvu — nesignalizuje funkčnost dokud nebyl test spuštěn. Po testu: zelená (vše OK), oranžová (částečně), červená (vše FAIL). Detail testu se streamuje do černého terminálového okna s barevně odlišenými řádky (URL, HTTP status, čas odezvy, číslo účtu, IBAN, zůstatek). Oprava: HTTP 409 (rate limit) už není reportován jako úspěch — je to samostatný stav rate_limit.
2026-05-28
v3.5 — Self-service Fio tokeny + Admin Test API
Klient si může spravovat své Fio API tokeny ve vlastním profilu (⚙️ Můj profil v dashboardu) — admin je nemusí znát. Nové endpointy /api/client/accounts (GET/POST/PUT/DELETE). V admin seznamu klientů nové tlačítko Test API — server otestuje všechny účty klienta bez expozice tokenů. Admin-managed cesta zůstává jako alternativa.
